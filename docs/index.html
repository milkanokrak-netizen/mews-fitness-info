Mew's Fitness Automation

A personal, non-commercial automation for preparing private daily and weekly fitness summaries.

The automation processes fitness information exported to Google Drive and uploads summary files to a restricted Google Drive folder using the account owner's authorization. Reports are intended for private review in ChatGPT.

This website is informational only. It does not display or host personal fitness records and has no sign-in form.
