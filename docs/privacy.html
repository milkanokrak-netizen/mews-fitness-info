Privacy Policy

Mew's Fitness Automation is a personal-use application operated by its Google account owner. Last updated: October 16, 2026.

Information processed

The automation processes fitness information supplied by the owner, including exported activity, workouts, nutrition, weight, sleep, and related wellness measurements. Google Drive OAuth is used to create or update report files in the owner's Google Drive.

How information is used

Information is used solely to prepare private daily and weekly fitness summaries. The automation is not a public-facing fitness service and does not sell data or use it for advertising.

Where information is stored

Source exports and generated reports are stored in the owner's Google Drive. GitHub Actions temporarily processes data during workflow execution. OAuth credentials are intended to be stored in GitHub Actions secrets, not in this website's files. The website does not publish fitness records.

Sharing

The owner controls access to their Google Drive files and any connected services. The automation does not intentionally make personal health or fitness reports public.

Access and deletion

The owner can remove report files and exports from Google Drive, remove GitHub Actions secrets, disable the workflow, and revoke Google access under Google Account third-party connections. Existing stored copies may need to be deleted separately.

Contact

For questions about this personal-use app, use the support email shown on its Google OAuth consent screen.
